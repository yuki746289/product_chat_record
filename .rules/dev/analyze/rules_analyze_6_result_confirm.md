# 分析 手順6: 分析結果確認

## 目的

分析が承認済み条件を省略せず完了し、再現可能で公平な結果になっているか確認します。

## 出力

`{analysis}_v{n}.{m}_6_result_confirm.md`

## 確認項目

- [ ] 承認済みの全workflowとjobが実行されている。
- [ ] 対象、期間、閾値、組み合わせ、評価指標および精度が無断変更されていない。
- [ ] 全件数が完了、失敗、明示的除外および未処理に一致し、未処理が0である。
- [ ] shardの欠落、重複、入力ハッシュ不一致および条件ハッシュ不一致がない。
- [ ] 0件、失敗、無相関および不利な結果も省略されていない。
- [ ] 並列数と実行順によって結果が変化していない。
- [ ] checkpointからの再開と再試行が重複結果を生んでいない。
- [ ] CODE、CHATGPT、HYBRIDおよびMANUALの実績がworkflow定義と一致している。
- [ ] ChatGPT分析の入力、プロンプト、条件、根拠および結果がGit管理されている。
- [ ] 入力、コード、依存関係、実行SHA、設定および乱数シードから再現できる。
- [ ] public側へprivate情報が出力されていない。
- [ ] 通知履歴、停滞、再試行、予想終了および実績終了が記録されている。
- [ ] 結論、根拠、限界、注意事項および未解決事項が明確である。

## 判定

未確認、未処理または説明のない除外が1件でもある場合は完了にしてはいけません。
結果を受けてコードや仕様の変更が必要な場合は、自動的に変更せず、app、batchまたはquick_fixの適切な工程を提案してユーザ承認を得て下さい。
