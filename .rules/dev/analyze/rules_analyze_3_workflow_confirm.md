# 分析 手順3: 分析条件・全体ワークフロー確認

## 目的

手順1と手順2を確認し、一括実行を開始できる状態か判定します。

## 出力

`{analysis}_v{n}.{m}_3_workflow_confirm.md`

## 確認項目

- [ ] 目的、対象、期間、除外、評価指標、完了条件および受入条件が確定している。
- [ ] AIが独自に範囲、精度、件数または分析方式を変更できない記述になっている。
- [ ] 全workflowとjobが一覧化され、ID、依存関係、入出力および完了条件が明確である。
- [ ] `CODE`、`CHATGPT`、`HYBRID`、`MANUAL`の選択理由が妥当である。
- [ ] 総処理件数、組み合わせ数、推定時間、shard、並列数およびtimeoutが算出されている。
- [ ] checkpoint、再開、冪等性、再試行および統合方法が定義されている。
- [ ] public/privateの公開可否表と実行リポジトリが確定している。
- [ ] public側のログ、artifact、cache、job名、通知からprivate情報を推測できない。
- [ ] 通知間隔、通知方法、停滞判定、即時通知および終了予定算出が定義されている。
- [ ] Actions、API、DB、runner、容量および認証の制限を確認している。
- [ ] 全件、失敗、除外、未処理および0件の記録方法が定義されている。
- [ ] MarkdownとJSONのworkflow定義が一致している。

## 一括実行の承認

全項目が合格し、ユーザが承認した場合のみ手順4へ進みます。
承認後は重大な停止条件がない限り、細かな追加確認を行わず手順4と手順5を一括して完了させます。
