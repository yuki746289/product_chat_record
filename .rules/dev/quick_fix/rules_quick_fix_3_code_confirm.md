# 簡易開発 手順3: コード確認

## 目的

手順2で修正したコードについて、修正内容、影響範囲および動作確認結果を確認します。
手順1で承認された修正内容とコード修正が一致していることを確認します。

## 確認対象

- 手順1で承認済みの `{filename}_v{n}.{m}_1_request.md`
- `99_仕様確認.md` の総合判定が合格である最新バージョンの `.document/v{prev}/00_index.md` と、そこから参照される全項目別仕様書
- 手順2で修正した `{filename}_v{n}.{m}.{code_ext}`
- 動作確認結果およびテスト結果

## 確認項目

- [ ] 手順1で承認された範囲内の修正であること。
- [ ] 要件、既存仕様、コードの間に矛盾がないこと。
- [ ] 対象外のコードや既存ロジックを不要に変更していないこと。
- [ ] 正常系、異常系および境界値の確認が行われていること。
- [ ] 既存機能にデグレが発生していないこと。
- [ ] 既存仕様を変更していないこと。
- [ ] 仕様書を作成、変更、削除していないこと。
- [ ] 仕様にない挙動をコードへ追加していないこと。
- [ ] 仕様変更を必要とする修正が含まれていないこと。

## 出力

確認結果は `{filename}_v{n}.{m}_3_code_confirm.md` として対象バージョンの格納フォルダへ出力して下さい。

## 仕様変更が判明した場合

仕様変更の必要性または仕様との矛盾が判明した場合は、作業を停止して内容をユーザへ報告して下さい。
通常開発へ切り替えるかユーザへ確認し、承認された場合のみ通常開発を手順1から開始して下さい。
ユーザの承認を得ずに通常開発へ切り替えてはいけません。
