# ECO-018 重要経済指標53グループの無料取得カバレッジ台帳（2026-10-20更新）

正本: `11_重要指標判定マスター.yaml` / `policy_version=2026-10-15.1`。
本台帳は固定マスター全53グループを機械的に列挙し、無料の公的機関カレンダーで**1件以上の予定を検証できたか**を記録する。市場に与える影響のS/A評価を更新するものではない。

## 証拠の区分
- **限定実証**: 少なくとも1件の日程をGitHub ActionsでHTTP取得し、固定マスターIDと共通JSON Schemaへ照合したもの。一次公表元または公的機関の二次カレンダーを必ず区別する（時刻未定の場合を含む）。
- **未検証**: 正式な無人取得・継続利用・全件網羅の実証なし。
- 実証となっていても**恒常的なAPI/公式予定の全件網羅、発表結果/予想、利用許諾、本番採用は全て未確定**。

## 不足を解消する順序
1. S級の残りの指標を無料公式発表元ごとに整理し、日時が確定/未定を分ける。NZDはRBNZが403のため無料の別公式経路を先に探索。
2. USDはBLSの403を回避せず、許諾された正式な取得元/配信形式を確認。金融政策/主要統計を混在させない。
3. EURはEurostatのICS個別日程、DEのCPI/PMIを別管理（EUとDEの国コードの混同禁止）。
4. 民間PMI・民間景況感など公的統計だけでは揃わない項目は「未網羅」として利用者画面に明示。無料という費用条件を崩さない。
5. 速報/改定/重複の別名対応は、取得元ごとに厳密一致クロスウォークを検証してから適用する。
6. 7通貨・53グループ全件の収集と、利用規約/画像化/自動実行、EXE、Windows実機テストは**未合格**。release_0.2.0作成不可。
