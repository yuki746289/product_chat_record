# ECO-021 米国6指標の一次発表機関との日時照合（2026-10-19）

## 検証目的と判定の粒度
FRED（セントルイス連邦準備銀行）の**公的二次カレンダー**から取得済みの米国6系列を、BLS・BEA・Census Bureauの**一次公表日程**と照合する。

照合結果と実装可否を分離する。
- **日程一致**: 発表予定日・現地発表時刻が一次機関の公式予定とFREDの公表予定とで一致。
- **一次機関のHTTP取得成功**: GitHub Actionsで実際の一次公表元の公式データにHTTP200で接続できたこと。
- **機械可読イベント・JSON Schema合格**: 一次元のイベントUID/名称/日時を抽出し、既存S/A・共通JSON Schemaに適合。
- **本番利用条件クリア**: 継続自動取得、ローカル保存、PNG化/再利用条件・障害時対応の完了。**今回は未達**。

## 運用設計の優先順位
1. 個別指標の原公表機関から承認済みの機械可読日程（例: **BEA ICS**）を取得できる場合はそれを優先。
2. 原公表機関の公式Web掲載は日時の**確認元**として扱う。HTMLをGitHub Actionsから取得できず403となる場合、これを自動取得成功と表記しない。
3. FREDは公的な二次日程の**補完・照合用候補**。原公表元と矛盾する場合には原公表元を優先し、例外を監査に残す。別ソースの数値がない項目は`null`。
4. 情報源ごとの取得失敗と、特定の日にイベントがない状態は混同しない。`PARTIAL`/`INCOMPLETE`を維持する。
5. 月額0円の厳守、著作物/第三者情報の引用条件、出典と最終更新の記録、ソースの構造変化への耐性が本番採用条件。

## NZ・Eurostatの確認済み限界
- NZのStats NZサイトは、人間向けWeb表示では2026年10月22日のCPI予定とICSへの案内を確認できる。しかしGitHub Actionsの静的HTMLには予定本文・ICSダウンロードURLが現れず、**NZDの自動取得は0/6のまま**。
- NZ中銀の個別ページはGitHub ActionsからHTTP403。アクセス制限を迂回する実装は行わない。
- Eurostatは2026年のICSカレンダー提供を公式に案内しているが、こちらのActions試験では個別ICS URL・イベント本文の取得は未達。
