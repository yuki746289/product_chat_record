# 概要・対象範囲

## ECO-001 目的
Windows ChartRecorder の起動時に、**日本時間の当日の重要経済指標一覧を画像化して自動表示**し、為替取引の前に当日の主要発表を一度に把握する。チャートの画像と日次イベント画像は別に生成する。

## ECO-002 対象範囲
- 出力は **1日1枚**。通貨ごと・通貨ペアごとに分けない。
- 対象通貨: `USD, JPY, EUR, GBP, AUD, NZD, CAD`。
- 独自重要度 `S`（最重要）と `A`（重要）のみ表示。一般のカレンダーが与える星や重要度は独自判定の代わりにしない。
- 日本時間（Asia/Tokyo）00:00〜翌00:00未満のイベントを日時昇順に表示する。
- 同時刻・同系統の複数指標は1グループにまとめる。指標の内訳は失わない。
- 起動時、既存の当日画像があれば表示し、通常は再取得・再生成しない。
- 新規生成後は Windows の既定画像ビューアで開く。
- 当日0件の場合も「本日の重要経済指標はありません」と明示した1枚を生成する。ただし取得失敗を0件扱いしない。

## 非対象（初版）
- 通貨ペア別PNG、チャートへの経済指標縦線描画・埋め込み。
- B級イベントの表示、指標に基づく自動売買や売買シグナル。
- 発表後の画像の常時再更新、イベント前通知、経済ニュースの解釈。
- TradingView Webチャート本体への書込み。
- レイアウトのピクセル寸法・色・フォント等は後続設計。

## 既存仕様の維持
`setting.yaml`、`system.yaml`、Windows setup.exe 選択先、Saxo認証、既存13ペアのチャート生成、5分間隔、最新10日時フォルダ保持、二重起動時の確認は変更しない。

## 用語
- **経済イベント**: 指標発表または政策決定・中央銀行総裁等の指定イベント。
- **独自S/A**: 本仕様の通貨別マスターに基づく固定優先度（市場の実測影響ランキングではない）。
- **当日**: PC の `Asia/Tokyo` で算出した暦日。
- **日次画像**: `economic_events_YYYYMMDD.png`。チャートの5分スナップショットとは独立。
