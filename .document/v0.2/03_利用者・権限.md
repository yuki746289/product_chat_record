# 利用者・権限

## ECO-003 利用者
- 想定利用者: Windows に ChartRecorder をインストールして利用する当該OSユーザー。
- 閲覧: 利用者のローカル出力先内の日次PNGを、既定画像ビューアで開く。
- 登録・更新: アプリの自動生成。既存画像の再生成は初版の通常起動では行わない。
- 削除: 日次ファイルの自動削除・保持年限は未確定。チャート10フォルダ保持処理の削除対象には含めない。
- 管理者権限を前提とせず、従来のインストール先への書込み権限を使用する。

## 権限境界
- SaxoのOAuth・資格情報と経済カレンダー連携の資格情報は分離する。
- 外部APIの認証方式、利用許諾、再配布範囲は未確定（ECO-007）。
- 今回はユーザー管理画面・ロール分離・サーバ側権限管理は対象外。
- 権限不足の場合はログとユーザーに把握できるメッセージを残し、既存のチャート処理を妨げない。
